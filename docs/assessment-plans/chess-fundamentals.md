## Proposed scope for subject review

The following topic outline is a draft for the team's reviewers to accept, narrow or replace. It is not an approved syllabus, item blueprint or institutional endorsement.

Learning-objective drafts:

- Explain legal moves, check and basic game-state concepts.
- Apply a stated chess ruleset to an unambiguous position.

Basic topic outline:

- Board coordinates and piece movement
- Legal moves and check
- Checkmate versus stalemate
- Castling/en passant/promotion
- Basic tactics and king safety

Advanced scenario outline:

- Select a legal tactical response in a fully specified position
- Distinguish a game-ending condition from check alone
- Compare candidate moves under explicit objectives; avoid ungraded subjective best-move claims

## Existing engine contract to preserve

Basic: 10 equally weighted `MULTIPLE_CHOICE` items per attempt, initially 80%, default 20 minutes. Advanced: 5–10 `APPLIED_CHOICE` scenario items per attempt, initially 80%, default 45 minutes, after this offered skill's actual basic pass/Amateur prerequisite. Current retake policy: three starts per rolling 168 hours per level, 24-hour failure/expiry cooldown. Do not edit these policies through content planning.

Each curated pool must contain at least the attempt's question count and at most 200 items. Reviewers choose the pool size; a pool exactly equal to the attempt size randomizes ordering but cannot vary the selected question set. Questions and answer order are randomized by the existing backend. Do not invent a new required pool size or minimum-attempt rule.

For each future authored item, reviewers must complete: kind, prompt, competency/outcome, points, exactly one correct option, distractors, and a grading rationale/rubric explaining correctness and ambiguity limits. Put the rationale in the existing private `rubric` field; do not send new unsupported fields to the import API. Basic points must remain one per item. Never expose the key/rubric in public profiles or submit a frontend-computed score.
